# SecureFileEncryptor

SecureFileEncryptor is a modern, high-performance file encryption and decryption application built with **C++23**. It allows users to securely encrypt files and folders using industry-standard cryptographic algorithms while maintaining excellent performance, scalability, and security.

The project follows modern C++ best practices, including RAII, smart pointers, SOLID principles, and a modular architecture for maintainability and future expansion.

---

## Features

- AES-256-GCM File Encryption
- RSA-4096 Key Encryption
- Password-Based Encryption (PBKDF2)
- SHA-256 & SHA-512 Hashing
- File Integrity Verification
- Secure Random Key Generation
- Encrypt Single Files
- Encrypt Multiple Files
- Encrypt Entire Folders
- Recursive Folder Processing
- Large File Support (Streaming)
- Cross-Platform (Windows, Linux, macOS)
- JSON Configuration
- Detailed Logging
- Command-Line Interface
- Unit Testing with GoogleTest
- Modular Architecture
- High Performance
- High Reliability

## Security

SecureFileEncryptor implements modern cryptographic best practices.

- AES-256-GCM Authenticated Encryption
- RSA-4096 Public-Key Encryption
- PBKDF2 Password-Based Key Derivation
- SHA-256 & SHA-512 Hashing
- HMAC Authentication
- Secure Random Number Generation
- Constant-Time Comparisons
- Memory Zeroization
- Chunk-Based File Processing
